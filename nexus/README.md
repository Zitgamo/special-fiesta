# 🛰️ Sovereign Nexus: Tactical Dashboards

The **Sovereign Nexus** is a collection of high-fidelity, real-time dashboards designed to provide absolute tactical transparency into the fleet's operations.

## 🖥️ Available Dashboards

### 1. [**Sovereign Nexus**](file:///c:/Users/ADMIN/Desktop/IRON_COMMANDER_ELITE/nexus/sovereign_nexus.html)
The primary command center.
- **Features:** Global account metrics, unit status (ALPHA/OMEGA/GAMMA), active strike cards, and real-time PnL tracking.
- **Usage:** Use this for general overwatch during live trading sessions.

### 2. [**Elite Focus**](file:///c:/Users/ADMIN/Desktop/IRON_COMMANDER_ELITE/nexus/elite_focus.html)
Deep-dive analysis into specific high-conviction assets.
- **Features:** Advanced charting, session bias indicators, and detailed unit telemetry.
- **Usage:** Use this when a specific unit is engaged in a high-stakes trade.

### 3. [**Southern Command**](file:///c:/Users/ADMIN/Desktop/IRON_COMMANDER_ELITE/nexus/southern_command.html)
Dedicated interface for the Vietnam (VN30) tactical front.
- **Features:** VN30 Index Futures performance, paper-trading logs, and Asia-session specific analytics.
- **Usage:** Monitoring alpha harvesting in the Eastern markets.

### 4. [**Elite Report**](file:///c:/Users/ADMIN/Desktop/IRON_COMMANDER_ELITE/nexus/elite_report.html)
Post-operation forensic analysis.
- **Features:** Performance heatmaps, mutation logs, and historical equity curves.
- **Usage:** Periodic review of fleet effectiveness and strategy evolution.

## 🔌 Technical Integration
The dashboards are built with HTML/JavaScript and communicate with the core engine via the [**`nexus_bridge.py`**](file:///c:/Users/ADMIN/Desktop/IRON_COMMANDER_ELITE/core_v3/nexus_bridge.py) which serves data from the `iron_core.db`.

**Design Philosophy:** Aesthetics are functional. Clear visuals eliminate cognitive load during high-volatility events.
