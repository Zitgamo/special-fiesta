## 🏛️ THE ARCHITECTURAL CORE
The Librarian Agent was created to solve the "Context Drift" problem in autonomous coding. When multiple agents or sessions work on the same codebase, documentation becomes the only source of truth.

### 1. THE CANONICAL STRUCTURE
- **ERRORS/**: Every bug ever hit + the fix applied.
- **PROTOCOL/**: Coding rules, deployment steps, and risk guards.
- **ARCHITECTURE/**: System maps and logic definitions.
- **HANDOVER/**: The active mission and done logs.

### 2. THE LIBRARIAN'S DUTIES
- **GUARD**: Prevent editing of `LOCKED` files without authorization.
- **LOG**: Automatically record errors and fixes into the permanent history.
- **INDEX**: Maintain `00_INDEX.md` as the single entry point for all agents.
- **RELEASE**: Prepare clean, noise-free bundles for commercial distribution.
