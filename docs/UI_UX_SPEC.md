# 🎭 SOVEREIGN UI/UX SPECIFICATION (V1.0)
## Project: IRON COMMANDER ELITE

### 🎯 NGUYÊN TẮC THIẾT KẾ: "DEADLY ELEGANCE"
1. **Dữ liệu là tối thượng**: Mọi hiệu ứng đẹp mắt phải phục vụ việc làm nổi bật thông số giao dịch. Nếu không thể đọc được PnL trong 0.5 giây, thiết kế đó là THẤT BẠI.
2. **Cân bằng Ruột/Vỏ**: Không over-engineer UI khi logic chưa hoàn thiện. UI không được chiếm dụng quá nhiều CPU của hệ thống.
3. **Hiệu năng**: Không dùng thư viện nặng (No React/Vue). Ưu tiên Vanilla HTML/CSS để đảm bảo tốc độ tối đa.

### 🏗️ CẤU TRÚC 3 CỘT (THE TRINITY LAYOUT)
- **Cột Trái (Command Center):** 
    - Cơ chế: **Horizontal Tabs** (Lật ngang).
    - Nội dung: Pool Monitor & Asset Scanner.
- **Cột Giữa (Tactical Fleet):** 
    - Cơ chế: **Vertical Scroll** (Cuộn dọc) với hiệu ứng làm mờ biên.
    - Nội dung: Trạng thái 3 Bots (ALPHA/OMEGA/GAMMA).
- **Cột Phải (Strategic Intel):** 
    - Cơ chế: **3D Card Flip / Stack** (Lật thẻ 3D).
    - Nội dung: Git Status, Real-time Log, Sovereign Scale.

### ⚖️ THÔNG SỐ CÁI CÂN (SOVEREIGN SCALE)
- **Logic Score (Back)**: Tính dựa trên số lượng lệnh, độ phức tạp của DNA và PnL thực tế.
- **Aesthetic Score (Front)**: Tính dựa trên số lượng hiệu ứng CSS và tính toàn vẹn của Layout.
- **Cảnh báo**: Nếu Front > Back + 30%, hệ thống sẽ báo trạng thái "LÃNG PHÍ HÌNH THỨC".
